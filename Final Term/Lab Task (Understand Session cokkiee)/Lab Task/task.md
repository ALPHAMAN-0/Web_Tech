Write a simple PHP program to demonstrate the use of session in a web application. Create a login page where a user can enter a username and password. If the login is successful, store the username in a session variable and redirect the user to a dashboard page. In the dashboard page, display a welcome message using the session data. Also implement a logout feature that destroys the session and redirects the user back to the login page. Your program should clearly show how session helps to maintain user login state across multiple pages.
